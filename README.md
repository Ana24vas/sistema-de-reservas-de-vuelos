# sistema-de-reservas-de-vuelos
Un sistema para buscar y reservar vuelos.
Este proyecto es una simulación básica de un sistema para buscar y reservar vuelos.
Está desarrollado en Java como parte de un ejercicio académico y aplica estructuras de datos como:

ArrayList: para almacenar los vuelos disponibles.

Árboles: para buscar vuelos por destino.

Colas: para manejar la lista de espera de vuelos llenos.

Ordenamiento: para mostrar los vuelos ordenados por precio o por horario.

Búsqueda binaria: para localizar rápidamente un vuelo por su número.

--Funcionalidades principales
Agregar nuevos vuelos.

Buscar vuelos por destino o número.

Reservar asientos (o pasar a lista de espera si está lleno).

Ver vuelos ordenados por precio u horario.
